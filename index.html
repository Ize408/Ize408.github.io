Featured · LLM / RAG

PCB RAG Assistant

Ask questions about PCB datasheets and production test logs, and get answers with cited sources. "What's the absolute max VIN of the AX3318?" or "Why did board CB-24-00127 fail?"

  • Hybrid keyword and vector search on Azure AI Search, so part numbers match exactly and plain questions match by meaning.
  • Every chunk is tagged with its document title and section; test logs are parsed into summaries before indexing.
  • Counting questions such as "which step fails most often?" go to a pandas statistics layer, because top-k retrieval can't count.
  • A strict prompt keeps absolute-maximum ratings apart from operating conditions and says so when the docs don't have the answer.
